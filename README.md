# AI Readiness Checklist for Service Firms

A practical checklist for accounting, law, engineering, insurance, and consulting firms assessing whether their data, workflows, people, and governance are ready for AI agents and private knowledge systems. Work through each section and tick off what is already in place.

## Data

- [ ] We know where client and firm data lives (systems, drives, inboxes).
- [ ] Sensitive and client-confidential data is classified and labeled.
- [ ] Key records are clean, current, and accessible via search or API.
- [ ] We have a clear owner for data quality.

## Workflows

- [ ] We have listed our top 10 repetitive, time-consuming workflows.
- [ ] Each candidate workflow has a documented, repeatable process.
- [ ] We have estimated hours saved per workflow.
- [ ] We have picked one low-risk pilot workflow.

## People & Approvals

- [ ] An executive sponsor is named for AI adoption.
- [ ] Staff know which AI tools are approved for use.
- [ ] Review and approval steps are defined for AI-generated work.
- [ ] Training time is scheduled for the team.

## Governance

- [ ] We have a written AI use policy.
- [ ] Client confidentiality and regulatory obligations are mapped to AI use.
- [ ] Vendor security and data-retention terms have been reviewed.
- [ ] Audit logs and human-in-the-loop checkpoints are in place.

## Measurement

- [ ] We have a baseline for time, cost, and error rates.
- [ ] Success metrics are defined for the pilot.
- [ ] We review results monthly.
- [ ] We have criteria to scale, adjust, or stop.
